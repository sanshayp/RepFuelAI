# RepFuelAI

RepFuelAI is a responsive React and Vite landing page for an AI-powered fitness and nutrition platform. It presents training styles, featured workouts, nutrition guidance, and the product's performance-focused brand direction.

## Tech stack

- React
- Vite
- JavaScript and JSX
- Modular CSS
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite. The project uses port `3000` by default.

## Available scripts

- `npm run dev` starts the development server.
- `npm run build` creates a production build in `dist`.
- `npm run preview` previews the production build locally.

## Project structure

- `src/components` contains reusable page sections and cards.
- `src/data/homePageContent.js` contains the page content and card data.
- `src/styles` contains shared variables, animations, and component styles.
- `public` contains static public assets.

## Scope

This milestone is a static landing page. Authentication, backend APIs, calculators, forms, and personalized medical or dietary advice are outside the current scope.
